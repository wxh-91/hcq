# HCQ

一个基于 NoneBot2 的 QQ 个人助理机器人。

## 功能

- 多模型策略分流（闲聊 / 工具 / 备用）
- 语义意图判断（自动区分工具调用与闲聊）
- 工具调用（文件读写、命令执行、视频下载、签到等）
- 任务队列（全角星号 ＊ 分隔多任务，按分数排序串行执行）
- 权重系统（工具成功经验分，半衰期 15 天指数衰减）
- 情景记忆（当天对话落盘，跨天自动清理）
- Pi 后端集成（可选）

## 快速开始

1. 安装依赖：pip install -r requirements.txt
2. 配置环境变量：复制 .env.example 为 .env，填入中转站地址与 API Key
3. 配置模型策略：复制 models.json.example 为 models.json，填入模型配置
4. 启动：python3 dz.py
