# 09 配置与模型策略

> 本文件集中说明模型配置结构、环境变量入口与运行配置边界。身份标识项见 [06_权限与审计.md]；编排分支见 [03_意图与对话编排.md]。

## 1. 模型配置文件

模型配置以模型名为键，是唯一的路由依据：前端/调用方选哪个模型，后端就用哪个模型发请求；不按任务意图分类，不静默换模型。

顶层字段：

- `default_model`：未显式指定模型时使用的默认模型。
- `models`：模型表，键为真实模型名。
- `role_aliases`：历史岗位名到真实模型名的兼容别名表，仅服务历史内部调用点，不参与“按任务选模型”判断。
- `auto_model_fallback`：关闭状态；模型失败如实报错，不自动切到其他模型。

## 2. 模型表条目字段

| 字段 | 含义 |
|---|---|
| `model` | 发往上游的上游模型名 |
| `provider` / `base_url` | 上游提供方与接口地址 |
| `api_keys` | 上游密钥列表（机密，不写入文档与日志） |
| `kind` | 通道类型：`openai`（默认 API 类）、`c-end-web`（C 端网页通道） |
| `supports_tools` | 该模型是否装配工具 schema；C 端网页通道为 `false` |
| `timeout` | 单次请求超时（秒） |
| `enabled` / `conversation_memory` | C 端通道启用标记与会话记忆标记 |

## 3. 模型解析顺序

模型名到配置的解析顺序：

1. 真实模型名精确匹配；
2. 忽略大小写匹配；
3. 历史别名表翻译后再解析；
4. 旧结构兼容读取。

全部落空返回空：调用方必须如实报未知模型，禁止静默替换。C 端通道条目 `kind=c-end-web` 时走 C 端封装且不提供工具；其余 API 模型按 `supports_tools` 决定是否装配工具。

## 4. 环境变量入口

| 变量 | 用途 |
|---|---|
| `FEISHU_ENABLED` | 飞书适配器总开关；显式关闭时不注册长连接 |
| `ONEBOT_WS_URLS` | OneBot 地址列表；为空则不注册该适配器 |
| `NEWAPI_BASE` | API 中转站地址 |
| `NEWAPI_KEY` / `NEWAPI_KEY_1` 起 | API 密钥；支持多键轮转，缺省回退单键 |
| `BACKUP_BASE` / `BACKUP_KEY` | 备用上游地址与密钥（可选） |
| `MODEL_NAME` | 配置文件缺省时的兜底默认模型名 |
| `CHECKIN_ENABLED` | 签到功能开关 |
| `FEISHU_ADMIN_OPEN_ID` | 飞书端主管理员标识 |
| `DEEPSEEK_USER_TOKEN` | C 端网页通道认证令牌 |
| `MOBILE_API_KEY` | 后端高危门禁的回退凭证；未带角色且非可信本地来源时恒定时间比对，期望为空则失败关闭；机密值不入文档与日志 |
| `TRUSTED_LOCAL_HOSTS` | 逗号分隔的额外可信本地地址；回环地址之外的本地放行地址只由该清单显式追加 |

环境变量经 `.env` 加载；机密值不进入文档、示例与审计参数。

## 5. 运行配置中心

配置中心文件为人类把关的只读入口，AI 与工具不得经脚本或工具自动改写。当前配置项域包括：

- C 端通道总闸；
- API 请求超时；
- 上下文压缩阈值；
- 长期记忆条数上限；
- 神授与大型任务步数上限；
- 防御巡检间隔；
- 爬虫工具目录等路径常量。

修改运行配置后需重启生效；受保护配置的改写意图由只读守卫在工具执行前拦截，见 [06_权限与审计.md] 与 [08_业务闭环索引.md]。

## 6. 何时查本文档

- 前端可选模型与配置表不一致。
- 模型名解析失败、被静默换成别的模型。
- C 端通道是否提供工具、是否带会话记忆存疑。
- 适配器是否注册、超时与阈值不符预期。
- 接入模型或调整上游密钥应改哪个入口。
