# 04 记忆与知识体系

> 本文件划分记忆与知识的层次、载体与读写边界。所有读写应经对应模块接口，不直接编辑库文件；坐标与文件名见 [10_生产坐标红线与运维规程.md]。

## 1. 分层概览

| 层次 | 职责 | 载体 | 何时查 |
|---|---|---|---|
| 会话上下文 | 本轮与历史消息、压缩、裁剪、情节回写 | 记忆中心内存态 + 当日情节日志 | 上下文丢失、压缩异常、会话串味 |
| 长期记忆 | 跨会话保留的事实与人设 | 长期记忆状态文件 | 长期事实未记住、人格注入异常 |
| 知识库 | 偏好、历史解决方案、会话摘要、排错指南 | 知识库数据库 | 知识检索无结果、技能指南未命中 |
| 意图词库 | 二层分类词条、命中计数、来源 | 词库数据库 | 规则层未命中、误分流 |
| 经验库 | 高匹配历史执行轨迹、采纳/成功/失败计数、难负样本、工具版本 | 经验数据库 | 重复问题未复用经验、反馈计数不符 |
| 工具得分 | 工具选择排序依据与衰减 | 得分状态文件 | 工具排序异常、频繁选到低成功率工具 |
| 当日情节 | 当日对话情节沉淀，过期清理 | 情节日志 | 情节记忆缺失、跨日残留 |

## 2. 会话上下文（记忆中心）

- 编排层只经记忆中心取上下文、追加消息、触发压缩与裁剪；不绕过中心直写历史。
- 压缩判定基于令牌总量；压缩由中心调用无压缩通道完成摘要巩固，再替换早期历史。
- 会话隔离键由通道前缀与会话标识（sid）构成，不含模型名；同一聊天窗口切换模型共享同一份会话上下文，模型身份只作为请求字段下发，不参与分桶。测试沙盒会话与真实会话使用不同前缀分桶，前缀不赋予高危权限，见 [06_权限与审计.md]。
- 工具失败、超时与内部异常的状态经记忆中心回写本轮历史：失败工具报错以系统消息落库，超时/异常以助手状态消息落库，供下一轮承接；回写不绕过中心接口。
- 情节记忆在本轮结束时按会话回写；启动时清理过期情节。

## 3. 长期记忆与人设

- 长期记忆记录跨会话事实，有条数上限，超出时保留最近记录。
- 人格资料在启动时加载并进入系统上下文；资料文件为人类可维护的只读入口。
- 固定记忆写入指令直接落到长期记忆模块。

## 4. 知识库

知识库数据库按主题分表：用户偏好、历史解决方案、会话摘要、技能排错指南。

- 固定知识库查询指令按关键词检索解决方案并返回条目。
- 工具报错命中技能指南时，作为下一轮系统参考注入；指南与经验库是两套独立载体，不混用口径。

## 5. 意图词库

- 词库为意图漏斗第二层，零 API；词条带意图标签、命中计数、最近命中时间与来源。
- 规则层未命中时按词库匹配；可学习词条在使用中补充。
- 词库只做分流线索，不替代第三层模型判定。

## 6. 经验库（反馈闭环）

- 检索按关键词重合度与衰减计分，返回高匹配黄金轨迹；命中后计采纳。
- 反馈计数分三类：采纳、成功、失败；上轮命中经验后，本轮出现否定词时，上条轨迹失败计数加一。
- 难负样本用于检索惩罚；轨迹带工具版本，版本失效后不作为可靠参考。
- 经验库只提供参考轨迹，不决定工具权限与可见性。

## 7. 工具得分与情节

- 工具得分按成功记录与时间衰减更新，供工具排序参考；得分不是权限依据。
- 情节记忆只保留当日；过期内容在启动钩子与写入路径清理。

## 8. 读写边界

- 禁止绕过模块接口直接改写数据库表与状态文件。
- 记忆、知识、词库、经验、得分的统计口径在本文件与 [05_AUP协议与工具注册.md] 中分别表述，不互相借用边界。
- 引入记忆类载体时，先按 [00_元规范与更新协议.md] 的四问判定归属层次，再补入对应小节。
