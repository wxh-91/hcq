# 02 主引擎职责

> 本文件按“文件级职责 + 何时查”组织，不展开内部函数与实现细节。模块内部流程详见对应专题文档。

## 1. 入口与适配

### 入口脚本（dz.py）

- 职责：唯一启动入口；引导导入中心；协议端按环境变量条件注册，当前不启用外部协议连接；挂载本地 HTTP 路由；消息事件路由；别名前置物理解析；分段发送与发送兜底；启动后台巡检与情节记忆清理。
- 何时查：启动失败、消息未进入编排、别名未替换、HTTP 路由不可用、发送异常。
- 交叉引用：通道条件注册见 [09_配置与模型策略.md]；启动钩子与日志坐标见 [10_生产坐标红线与运维规程.md]。

## 2. 对话编排

### 编排主模块（ai.py）

- 职责：对话主入口；本轮模型选定与分支；意图漏斗判定；多轮工具循环；上下文压缩与裁剪；输出清洗；经验库检索注入；交付前证据校验；全局超时兜底。
- 何时查：意图误判、工具不调用、输出泄漏、上下文爆长、模型分支走错、回复缺工具结果支撑。
- 交叉引用：编排细节见 [03_意图与对话编排.md]；记忆装载见 [04_记忆与知识体系.md]。

## 3. 工具汇聚点

### 工具执行模块（admin.py）

- 职责：所有工具调用的唯一汇聚点；参数归一化；注册中心查询与可见性拦截；只读配置守卫；权限检查；审计记录；AUP 结果渲染；工具心跳等待。
- 何时查：工具执行失败、工具被判定下线、越权拦截、审计缺失、参数被错误解包。
- 交叉引用：协议契约见 [05_AUP协议与工具注册.md]；权限与审计口径见 [06_权限与审计.md]。

## 4. 模型与身份策略

### 策略解析模块（cl.py）

- 职责：主管理员身份判定；会话前缀用于测试沙盒与真实会话的上下文隔离；模型配置一次性加载；模型名到配置的解析（精确匹配、忽略大小写、历史别名兼容、旧结构兼容）；可选模型列表；默认模型取值。
- 何时查：管理员判定不符、模型名解析失败、默认模型不符预期、多端身份映射存疑。
- 交叉引用：模型配置结构见 [09_配置与模型策略.md]；身份放行规则见 [06_权限与审计.md]；外部鉴权与可信本地口径见 [12_插件生态与信任边界.md]。

## 5. 记忆与知识

### 长期记忆模块（memory.py）

- 职责：长期记忆记录与人格资料加载；知识库检索入口。
- 何时查：长期事实未被记住、人格注入异常、知识库检索无结果。

### 记忆中心（memory_center.py）

- 职责：会话上下文存储、取上下文、压缩判定与压缩、超上限裁剪、消息追加与情节回写；编排层不直写历史，统一经此模块。
- 何时查：上下文丢失、压缩过早或过晚、历史未按会话隔离。
- 交叉引用：完整分层见 [04_记忆与知识体系.md]。

## 6. 外部能力封装

### 图片识别模块（ocr.py）

- 职责：图片消息识别，识别结果按会话注入待消费上下文。
- 何时查：图片消息无响应、识别失败、图片文本未进入本轮对话。

### C 端网页通道封装（deepseek_web_integration.py）

- 职责：C 端网页版会话创建与续接、认证与请求头、挑战响应、流式/结果取回、按会话维护上下文；自身为不提供工具的模型通道。
- 何时查：C 端回复慢、降级、被风控、会话续接异常。
- 交叉引用：通道标识与开关见 [09_配置与模型策略.md]；熔断关系见 [03_意图与对话编排.md]。

### Pi 后端适配（pi_integration.py）

- 职责：Pi 模式切换与转发；后端子进程按需触发，启动时不初始化。
- 何时查：切换到 Pi 模式后异常；模式状态查询。

## 7. 基础设施模块

### 导入中心（import_center）

- 职责：服务注册与按名获取；启动引导。主引擎经服务名取编排、工具、注册中心等能力。

### 配置中心（config_center）

- 职责：集中读取运行配置；配置文件为人类把关的只读入口。
- 何时查：运行开关、阈值、步数上限与预期不符；配置项清单见 [09_配置与模型策略.md]。
