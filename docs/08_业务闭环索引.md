# 08 业务闭环索引

> 本文件按业务域归纳闭环、对外工具组与排查入口。工具可见性与注册口径见 [05_AUP协议与工具注册.md]；插件包划分见 [07_插件层与扩展契约.md]。工具名是稳定契约标识，不展开函数实现。

## 1. 站点采集与下载（crawler）

闭环：入口别名在进模型前解析为完整地址 → 编排判定工具意图 → 汇聚点执行采集宏工具 → 插件解析链路 → 子进程拉流 → 转码落盘 → 返回脱敏结果（状态与本地路径，不含原始链接与流地址）。

对外工具组：`crawl_video_link`、`crawl_custom_by_id`、`download_video_by_url`、`crawler_probe`、`crawler_dom_hook`、`crawler_run_node`。

何时查：下载无产物、标题或文件名异常、直链探测失败、子进程工作目录报错；产物落盘目录见 [10_生产坐标红线与运维规程.md]。

## 2. 联网检索（info_retrieval）

闭环：模型按工具描述选择检索工具 → 搜索或读取网页正文 → 结果回传编排层。

对外工具组：`web_search`、`read_webpage`、`search_and_read`。

何时查：搜索无结果、正文提取失败、外部实时信息未进入回复；先查审计日志与检索插件入口。

## 3. 定时任务（scheduler）

闭环：注册定时任务 → 任务持久化到调度库 → 到点触发并经通道提醒；支持取消与列表查询。单用户任务有数量上限。

对外工具组：`schedule_task`、`cancel_scheduled_task`、`list_scheduled_tasks`。

何时查：任务到点未触发、注册被拒、取消失败；查调度库与审计日志。

## 4. 重型任务（tasks）

三类自主调度形态，均经协议注册，受步数、时长与 token 约束：

- 神授模式：长周期自主循环；
- 大型任务：规划分解执行；
- 多任务队列：串行排队执行。

何时查：长任务中断、队列未执行、步数或时长限制异常；查任务调度记录与对应任务模块。

## 5. 系统与文件（system_ops）

对外工具组：`read_file`、`write_file`、`replace_line`、`delete_line`、`insert_line`、`summarize_large_file`、`system_status`、`ping_host`、`backup_project`；脚本执行本体由 `run_bash_script` 经汇聚点调用。

何时查：文件读写被路径穿越拦截、大文件摘要异常、系统状态查询失败、备份清单不符。文件改写类属高危，权限口径见 [06_权限与审计.md]。

## 6. 数据处理与鉴权抓取（data_utils）

对外工具组：`http_request`、`auth_http_request`、`auth_playwright_fetch`、`json_query`、`regex_extract`、`text_diff`、`web_security_audit`。

何时查：普通请求与鉴权请求混淆、结构化提取失败、页面需登录态、安全巡检无报告。

## 7. 绘图与代码产物（visual_arts）

对外工具组：`draw_math_functions`、`draw_geometric_shapes`、`render_python_code`。

闭环：命中后产物在本轮交付后物理隔离上下文，避免长代码污染后续闲聊。何时查：绘图无产物、代码产物未隔离、渲染报错。

## 8. Windows 操控（windows_control）

对外工具组：`interactive_browser`、`win_shell`、`win_ui_automation`。

闭环：本轮用户原话注入零信任校验，操控动作须对应用户明确请求；浏览器、shell 与原生控件分工具隔离。何时查：操控未响应、控件定位失败、鉴权会话失效；shell 类权限见 [06_权限与审计.md]。

## 9. 飞书投递（feishu_delivery）

对外工具组：`feishu_send_file`、`feishu_send_image`。

何时查：多模态投递工具执行失败、文件或图片未回传；投递通道经通知桥转发，状态坐标见 [10_生产坐标红线与运维规程.md]。

## 10. 系统修改提案（proposal_center）

对外工具组：`submit_system_proposal`。

闭环：涉及运行配置修改的意图不直接改写，而是形成提案由人类把关；只读守卫先于工具执行拦截受保护配置。何时查：配置改写被拦、提案未生成；配置边界见 [09_配置与模型策略.md]。

## 11. 全局辅助（core_utils）

承载下载器、签到、经验库、词库、情节记忆、工具得分、媒体处理、通知桥与安全扫描等跨插件辅助能力。各载体归属见 [04_记忆与知识体系.md]；高危辅助工具权限见 [06_权限与审计.md]。
